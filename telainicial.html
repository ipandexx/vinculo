Olá, Gemini. Vamos iniciar o desenvolvimento do meu RPG de Mesa Virtual chamado "Vínculo". O projeto será uma Single Page Application construída com HTML, CSS e JavaScript puros em um único arquivo, integrada ao Supabase e ao GitHub. NOSSAS REGRAS DE CONVÍVIO E DESENVOLVIMENTO: - Nós vamos trabalhar estritamente PASSO A PASSO, uma tela de cada vez. Você NUNCA vai gerar códigos de telas ou lógicas futuras (como lobby ou mesas de jogo) antes que eu valide e dê o "ok" na etapa atual. - Eu não possuo conhecimentos técnicos em programação. Você deve me guiar de forma simples, me dizendo onde criar os arquivos, como nomeá-los e como testá-los no meu computador. ESTILO VISUAL EXIGIDO (ROOTS MEDIEVAL): A interface deve ser extremamente limpa, intuitiva e profissional, mas com uma estética rústica, pesada e realista (nada de alta fantasia brilhante ou luzes neon). Use uma paleta de cores baseada em madeira escura envelhecida, bronze, ferro fundido e tons de pergaminho antigo para o fundo das caixas de texto. Utilize bordas sólidas com relevo simulando metal/madeira e fontes medievais discretas (via Google Fonts). O PRIMEIRO PASSO: TELA HOME E AUTENTICAÇÃO (SEM CAMPOS DE EMAIL) Crie o arquivo inicial do projeto (index.html) contendo apenas o essencial para a primeira página: 1. UMA INTRODUÇÃO DIRETA (HOME): Exibindo apenas o título "Vínculo" e uma breve mensagem imersiva. Abaixo, apenas um botão principal para direcionar o usuário para a próxima interface mantendo o mesmo HTML. 2. INTERFACE DE AUTENTICAÇÃO: Ao clicar no botão da Home, a tela deve transicionar (via JavaScript, ocultando a Home) para exibir diretamente na tela duas opções claras lado a lado ou fáceis de alternar: - Caixa de Login: Contendo apenas os campos para "ID do Usuário" (Username) e "Senha". Sem campo de e-mail. - Caixa de Criação de Conta: Contendo apenas os campos para "Escolha seu ID", "Senha" e "Repetir Senha". Não deve haver lacuna para preenchimento de e-mail e nem interface de confirmação de e-mail. Por favor, confirme que entendeu a exigência estética rústica, a ausência total de campos de e-mail nesta etapa de autenticação, e me forneça o código completo e limpo deste primeiro HTML para eu salvar como index.html e testar no meu navegador.
